# Project Demonstration

## Project Title
Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Demonstration Objective
The demonstration will show how the Standard Laptop procurement process is automated using ServiceNow Flow Designer.

## Demonstration Flow

The demonstration will cover the following steps:

1. Open ServiceNow.
2. Open Flow Designer.
3. Show the "Standard Laptop Task" flow.
4. Show the Service Catalog trigger.
5. Show the "Create Catalog Task" action.
6. Show the configured task details.
7. Show the Hardware assignment group.
8. Open Maintain Items.
9. Show the Standard Laptop service catalog item.
10. Show that the Standard Laptop item uses the created flow.
11. Open Service Catalog.
12. Select Hardware.
13. Select Standard Laptop.
14. Click Order Now.
15. Open the generated request.
16. Show the Approvers section.
17. Approve the request.
18. Open the Requested Item.
19. Open the Catalog Task.
20. Show the task short description and Hardware assignment group.

## Expected Demonstration Output

The demonstration should show that an approved Standard Laptop request generates a Catalog Task through Flow Designer and assigns the task to the Hardware group for laptop configuration.
